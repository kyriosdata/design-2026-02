# Objetivo

Elaborar uma primeira proposta de estratégia de observabilidade para a plataforma, a ser posteriormente refinada.

A proposta deve incluir:
* Quais informações devem ser observadas;
* Quais métricas são importantes;
* Como logs e traces podem ser utilizados;
* Como correlacionar uma requisição/fluxo entre os diferentes componentes;
* Quais informações não devem ser registradas por questões de privacidade;
* Quais indicadores podem ajudar a identificar problemas nos fluxos da plataforma.

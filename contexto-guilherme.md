# Diagrama de contexto — Plataforma estadual de interoperabilidade em saúde

**Sistema central:** Plataforma estadual de interoperabilidade em saúde.

**Quem interage com ela:**

| Ator/Sistema | Papel |
| --- | --- |
| Operador da Plataforma | Pessoa que opera/administra a plataforma |
| SISCAN | Sistema externo de informação do câncer |
| Aplicação Administrativa | Sistema cliente que consome/produz dados administrativos |
| Outra plataforma de interoperabilidade | Instância par (outra UF), trocando dados diretamente |
| Aplicação Clínica | Sistema cliente que produz/consome dados clínicos |
| RNDS | Rede Nacional de Dados em Saúde, fonte/destino nacional de documentos |

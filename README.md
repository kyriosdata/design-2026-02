# Design de Software

As mensagens de commit e os títulos de pull request deste repositório seguem a
especificação [Conventional Commits 1.0.0](https://www.conventionalcommits.org/pt-br/v1.0.0/).
Antes de contribuir, veja [CONTRIBUTING.md](CONTRIBUTING.md) e habilite a
verificação local:

```bash
git config core.hooksPath .githooks
git config commit.template .gitmessage
```
